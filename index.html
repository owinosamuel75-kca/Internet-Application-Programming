HTML Basics

Introduction to HTML

HTML stands for HyperText Markup Language. It is used to create and structure content on web pages.

Basic HTML Tags

HTML uses different tags to define the structure and content of a web page.

The <html> tag defines the entire HTML document.

The <head> tag contains information about the web page, such as its title.

The <body> tag contains the visible content of the web page.

The <h1> to <h6> tags are used to create headings of different sizes.

The <p> tag is used to create a paragraph.

Listing Tags

The <ol> tag is used to create an ordered list, while the <li> tag is used to define each item in the list.

Table Tags

The <table> tag is used to create a table. The <tr> tag creates a table row, the <th> tag creates a table heading, and the <td> tag creates a table data cell.
